# Sandstone Fast Rails — Minecraft 26.3

Fabric 模组：普通砂岩（`minecraft:sandstone`）上的铁轨使用动能模型，矿车最高可达 40 格/秒。

## 安装

需要 Minecraft Java 26.3、Java 25、Fabric Loader 0.19.5+、适配 26.3 的 Fabric API。
将 `build/libs/sandstone_fast_rails-1.1.0+26.3.jar` 替换服务器 `mods` 中的旧版后重启。
单人游戏安装到客户端 `mods`。不要同时安装两个版本，或安装 `-sources.jar` 源码包。

## 1.1.0 动能模型

矿车驶上砂岩铁轨后，由模组记录其轨道速度 V（格/tick），动能 E = V²/2。每 tick：

| 位置 | 能量 / 速度变化 |
|---|---|
| 砂岩上充能的动力铁轨 | 每经过 1 格增加 0.5 能量（约 4–6 格从静止加速到满速） |
| 其它方块上充能的动力铁轨 | 已加速矿车每格速度减半，最多减到原版动力铁轨速度（0.4 格/tick），随后交还原版 |
| 砂岩上未充能的动力铁轨 | 强力急刹：每格速度只保留 2%，每 tick 再 ×0.25，低于 0.05 直接停下（约 1–2 格内停住） |
| 其它方块上未充能的动力铁轨 | 较弱刹车：已加速矿车每格速度减半；降到原版速度后按原版刹车 |
| 所有铁轨 | 每 tick 乘原版减速系数 f（空车 0.96，载人 0.997） |
| 弯道 / 路口 | 只改变方向，不消耗能量 |
| 坡道 | 高度与动能互换：每升高 1 格消耗 0.0245 能量（真实重力），下坡返还 |

- 最高速度 2 格/tick（40 格/秒），任何情况下不会超过。
- 移动方式：原版先移动一次，剩余距离用最多 16 次原版 `moveAlongTrack` 小步（每步 ≤ 0.4 格）完成。弯道、路口、坡道、探测铁轨都按原版几何处理，任意速度下都不会脱轨。小步只移动矿车，不改变速度；载人矿车的 0.75 移动系数也会被补足，因此载人矿车过弯不再变慢。
- 离开砂岩后保留动能，按原版系数 f 逐渐减速；非砂岩铁轨（动力铁轨、下坡）不会再让它加速。降到原版速度以内时无缝交还原版逻辑，没有突然减速。
- 未经过砂岩的矿车完全使用原版逻辑，模组不做任何修改。
- 从静止启动时保留原版的推动（玩家输入、动力铁轨靠方块起步、实体推动）。
- 铁轨尽头照常驶出轨道。
- 仅影响普通矿车（`minecraft:minecart`）；实验性矿车物理下不启用。

## 构建和测试

```powershell
.\gradlew.bat build
.\gradlew.bat runGameTest   # 游戏测试需单独运行，build 不会运行
```

Gradle 9.6.0、Loom 1.17.21、Fabric API 0.161.0+26.3。
`src/gametest` 是独立测试模组，不会打入发布 JAR。测试覆盖：普通方块铁轨与原版一致、砂岩路口走向与原版一致、砂岩直轨摩擦等于原版 f、动力铁轨加速到但不超过 40 格/秒、弯道与探测铁轨不额外减速、离开砂岩平滑滑行、普通动力铁轨把已加速矿车减到原版速度、砂岩刹车强于普通刹车、翻越坡道只损失摩擦，且全程不脱轨。

## GitHub Actions

每次 push 到 master、Pull Request 或手动触发时，`.github/workflows/build.yml` 用 Java 25 运行 `./gradlew build`，并把 `build/libs` 中的 JAR 作为构建产物上传（不运行游戏测试）。
