# Sandstone Fast Rails — Minecraft 26.3

Fabric 模组，使普通砂岩（`minecraft:sandstone`）上的矿车轨道加速。

## 安装

需要 Minecraft Java 26.3、Java 25、Fabric Loader 0.19.5+、适配 26.3 的 Fabric API。
将 `build/libs/sandstone_fast_rails-1.0.3+26.3.jar` 替换服务器 `mods` 中的旧版后重启。
单人游戏安装到客户端 `mods`。不要同时安装两个版本，或安装 `-sources.jar` 源码包。

## 1.0.3 普通轨道滑行刹停

离开砂岩后，普通方块上的直轨、弯轨统一保留驶入时的惯性，按原版空车/载人摩擦每 tick 减速一次。材质交界也使用短步移动，避免旧逻辑把矿车传送到下一格中心而丢失部分行程。实际轨道不是砂岩时，禁止根据附近的砂岩预测位置重新加速或拉回矿车。

每 tick 额外移动期间不重复扣除摩擦。总移动速度低于约 0.003 格/tick 时清零并结束加速惯性；之后仍按普通矿车处理，不留微小持续滑动。动力铁轨的供能/制动仍按其自身机制处理。

新增长直道停车测试：圆石、石头、橡木木板三类支撑，空车/载人两种状态；逐 tick 检查原版摩擦、平滑滑行、不脱轨、最终静止及静止后不自行重启。

## 1.0.2 弯道减速修复

- 砂岩普通弯轨及其衔接区每 tick 的自然摩擦损失降至 0.1%，且保留额外移动，不再突然切回 1 倍移动速度。
- 弯道使用原版轨道物理分成小步移动，每步重新读取轨道和处理碰撞，不再自行选择弯道出口或直接传送到弯轨中心。
- 从砂岩轨道进入圆石等普通支撑方块时保留已有惯性，每 tick 仅应用一次原版摩擦，按原版空车/载人系数逐渐减速；额外移动步骤不会重复扣除摩擦。
- 未经过砂岩加速的圆石矿车仍使用原版速度和运动。
- 直线砂岩加速参数保持原有设定；坡道、未供能动力铁轨和水中不执行额外弯道移动。实验性矿车物理不启用此新增的小步过弯逻辑。

## 构建和测试

```powershell
.\gradlew.bat build
```

Gradle 9.6.0、Loom 1.17.21、Fabric API 0.161.0+26.3。
`src/gametest` 是独立测试模组，不会打入发布 JAR。测试覆盖四种弯轨、四个方向、两种初速度、两种砂岩布局的路口方向和不脱轨检查，并对比圆石原版逐 tick 轨迹；另检查空车/载人砂岩弯轨摩擦、从砂岩到圆石的惯性和单次原版摩擦，以及直线加速。
测试使用构建目录内的临时世界。
